## 🧪 What I'm Building

I build **Squetika Chromat** — a 21 CFR Part 11 compliant digital HPLC Laboratory Information System that captures tamper-proof chromatographic data with SHA-256 hash chaining, electronic signatures, and immutable audit trails.

My focus is on **data integrity in regulated GxP environments** — where records must be cryptographically sealed, auditable, and impossible to alter.

- 🔐 **Tamper-proof records** — SHA-256 hash chains on every record & audit entry
- ✍️ **Electronic signatures** — password re-entry, meaning, and timestamp (21 CFR 11.200)
- 📊 **Real-time lab dashboards** — live instrument status, OOS tracking, activity feeds
- 🛡️ **Role-based access** — Admin, QA Manager, Reviewer, Analyst with JWT auth
- 🖥️ **Windows Service connector** — .NET 8 agent that pulls data directly from Chromeleon / Shimadzu HPLC software
